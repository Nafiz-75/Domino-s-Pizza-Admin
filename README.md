# Domino's Bangladesh redesign: Admin dashboard

**Unofficial portfolio concept. Not affiliated with or endorsed by Domino's.**

Live: https://nafiz-75.github.io/Domino-s-Pizza-Admin/
Controls the shop at https://nafiz-75.github.io/Domino-s-Pizza-website-Redesign/

This repo holds the built admin only. Source, docs and build steps are in
[Domino-s-Pizza-website-Redesign](https://github.com/Nafiz-75/Domino-s-Pizza-website-Redesign) (`ADMIN.md`, `npm run build:admin`).

Prototype: everything is stored in the visitor's own browser. Changes you publish
show on the shop in that same browser, not for other visitors. The passcode only protects this device.
